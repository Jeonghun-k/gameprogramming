
# 🐱 고로캣: 햇빛 탈환 작전

> 허접한 원본 게임을 **프롬프트 34개**로 하나씩 업그레이드해 만든 브라우저 탄막 생존 웹게임

게임프로그래밍 과제 · 경성대학교 소프트웨어학과 곽정훈

---

## 📖 세계관

고로케 몸통에 고양이 귀·꼬리·팔다리가 달린 이족보행 고양이 **고로캣**.
고양이는 햇빛을 좋아하는데, 외계인 **선노(Sunno)** 가 지구의 햇빛을 빼앗아 갔다.
고로캣은 외계인들을 무찌르며 햇빛 조각을 모아 빼앗긴 햇빛을 되찾으러 간다.

---

## ▶️ 실행 방법

설치, 서버, 인터넷 연결이 모두 필요 없습니다.

1. `gorocat.html`을 내려받습니다.
2. 더블클릭해서 브라우저(Chrome, Edge 등)로 엽니다.

VS Code·Antigravity의 Live Server로 열어도 똑같이 실행됩니다.

## 🕹️ 게임 구성

### 캐릭터 3종

| 캐릭터 | 역할 | E 스킬 | R 스킬 |
|---|---|---|---|
| 감자 고로캣 | 검 · 균형형 | 돌진 베기 | 회전 검무 |
| 카레 고로캣 | 총 · 화력형 | 폭풍 난사 | 카레 대포 |
| 크림 고로캣 | 방패 · 탱커형 | 철벽 태세 | 황금 수호 |

### 라운드와 보스

| 라운드 | 보스 |
|---|---|
| 1 | 말랑 슬라임 대왕 |
| 2 | 솔라 태양 수호자 |
| 3 | 오르빗 UFO 사령관 |
| 4 | 최종 보스 **선노 (Sunno)** |

라운드마다 맵 디자인, 배경음악, 밝기가 달라지고, 보스를 쓰러뜨릴수록 어두웠던 맵이 밝아집니다.

### 성장 요소

- **레벨업 카드:** 적이 떨어뜨린 햇빛 조각(경험치)을 모아 레벨업하고, 카드 3장 중 하나를 골라 강화
- **공용 스킬:** 뜨거운 기름 장판 · 소스 레이저 · 튀김 방패 (업그레이드할수록 범위·피해·크기 증가)
- **아이템:** 체력 회복 · 자석 · 랜덤 박스
- **상점:** 모은 골드로 기본 체력, 기본 공격력, 고유 스킬 쿨타임 영구 강화
- **난이도:** 쉬움 · 보통 · 어려움 (몬스터 수, 등장 속도, 체력, 공격력이 달라짐)
- **미니맵:** 넓은 맵에서 아이템과 적 위치 확인

### 저장

골드, 상점 강화, 볼륨, 난이도는 브라우저의 `localStorage`에 저장되어 다시 접속해도 이어집니다.
(같은 컴퓨터, 같은 브라우저에서만 유지됩니다.)

## 🛠️ 기술

- **HTML5 Canvas + 순수 JavaScript** (프레임워크, 게임 엔진, 외부 라이브러리 없음)
- 파일 하나(`gorocat.html`)에 HTML · CSS · JS · 그림(SVG) · 음악(Web Audio API)이 모두 들어 있음
- `requestAnimationFrame`으로 매 프레임 `update()` → `draw()` 반복

## ⚠️ 참고

- **시연용 설정:** 발표 시연을 위해 라운드마다 15초 뒤 보스가 등장하고(`ROUNDS`의 `duration`), 골드 100,000으로 시작합니다(`START_GOLD`).
- **주사율:** 게임 속도가 프레임 수에 맞춰져 있어 120Hz·144Hz 모니터에서는 60Hz보다 빠르게 움직입니다.
