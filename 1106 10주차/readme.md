# 코드파일과 바로 실행 가능한 exe파일 두가지를 업로드함
# ppt를 바로 열면 글자 깨짐이 발생하기에 같이 첨부 된 폰트파일을 설치 후 열면 글자 깨짐 현상 해결 가능

# 🐟 붕어빵 타이쿤

> 게임프로그래밍 · 응용 8-2-1 업그레이드 과제
> 발표: 2021563006 곽정훈

원본 `app8_2_1`은 야구 점수를 사람이 직접 입력하는 **스코어보드 프로그램**입니다.
이 프로젝트는 원본의 함수 구조(`draw_check02` / `display_scoreboard` / `control_scoreboard` / `gotoxy`)와
"정규 + 연장" 흐름을 그대로 유지하면서, 내용을 **붕어빵 가게 경영 게임**으로 바꾼 것입니다.

라이벌 가게 **'황금붕어'** 와 며칠 동안 매출 대결을 벌여, 총매출이 더 많은 쪽이 이깁니다.

## 📁 파일 구성

| 파일 | 설명 |
| --- | --- |
| `fish_bread_ver20.cpp` | 게임 소스 코드 (C/C++, Windows 콘솔) |
| `fish_bread_ver20.exe` | 실행 파일 (바로 실행 가능) |
| `붕어빵 타이쿤 발표.pptx` | 발표 자료 (원본 분석 + 업그레이드 항목) |
| `NanumGothicCoding-Regular-PPT.ttf`, `NanumGothicCoding-Bold-PPT.ttf` | 발표 자료의 코드 부분에 쓰인 글꼴 |

게임을 하면 실행 파일과 같은 폴더에 아래 파일이 자동으로 생깁니다. 저장소에는 올리지 않습니다.

| 파일 | 설명 |
| --- | --- |
| `bungeo_best.txt` | 난이도별 최고 기록 |
| `bungeo_save.txt` | 이어하기용 저장 파일 (게임이 끝나면 자동 삭제) |

## ▶ 실행 방법

### 1. 실행 파일로 실행 (가장 간단)

1. `fish_bread_ver20.exe`를 더블클릭합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
3. 창이 작다는 안내가 나오면 **창을 최대화**합니다. (필요한 크기: 가로 116칸 × 세로 30줄)

- `-static` 옵션으로 빌드해서, MinGW나 Visual Studio가 없는 컴퓨터에서도 실행됩니다.
- Windows 10 / 11에서 실행됩니다.
- 소리(효과음, 오프닝 음악)가 있으니 스피커를 켜 주세요.

### 2. 소스 코드로 빌드

**MinGW g++ (사용한 컴파일러: MinGW-w64 32비트 g++)**

```bash
g++ fish_bread_ver20.cpp -o fish_bread_ver20.exe -static
```

- `-static`을 넣어야 다른 컴퓨터에서 `libgcc_s_dw2-1.dll이 없습니다` 오류가 나지 않습니다.
- `-lwinmm`, `-fexec-charset=CP949` 옵션은 필요 없습니다. 한글 변환과 음악 DLL 불러오기를 실행 중에 처리합니다.

**VS Code**

`tasks.json`의 `args`에 `-static`을 추가한 뒤 F5로 실행합니다.

```json
"args": ["-g", "${file}", "-o", "${fileDirname}\\${fileBasenameNoExtension}.exe", "-static"]
```

**Visual Studio**

소스 파일이 BOM 없는 UTF-8로 저장되어 있습니다. 한글이 깨지면 파일을
**"UTF-8 (BOM 포함)"** 으로 다시 저장한 뒤 빌드해 주세요.

## 🎯 게임 목표

- 매일 **라이벌이 먼저** 장사하고, 그다음 **내가** 장사합니다. (원본의 초 / 말)
- **정규 3일**을 둘 다 모두 마친 뒤 총매출로 승패를 정합니다.
- 총매출이 같으면 **4~5일차 연장 영업**을 모두 마친 뒤 다시 판정합니다.
- 5일까지도 같으면 **무승부**입니다.

> 원본의 9회 + 연장 3회 구조를 정규 3일 + 연장 2일로 바꿨습니다.

## 📅 하루 흐름

1. **라이벌 영업**: 라이벌 '황금붕어'의 그날 매출이 먼저 공개됩니다.
2. **아침 준비**: 붕어빵 1마리 가격을 정합니다 (500원 ~ 1,500원, 100원 단위).
3. **영업 (45초)**: 붕어빵을 구워서 손님에게 팝니다.
4. **마감 정산**: 그날 매출이 전광판에 기록됩니다. 팔지 못한 붕어빵은 버립니다.
5. **상점**: 번 돈으로 가게를 업그레이드합니다. 상점에서 나오면 **자동 저장**됩니다.

## 🔥 붕어빵 굽는 법

```
빈 틀 --SPACE--> 반죽 --1 또는 2--> 앞면 굽기
      --SPACE(뒤집기)--> 뒷면 굽기 --SPACE(꺼내기)--> 진열대에 2마리!
```

| 게이지 | 상태 |
| --- | --- |
| `######......` 초록 | 굽는 중 (한 면에 2.5초) |
| `############` 노랑 | 다 익음! 지금 SPACE |
| `############` 빨강 깜빡임 | 곧 타요! 서두르세요 |
| `XXXXXXXXXXXX` | 탐: 실수 +1, SPACE로 버리고 다시 굽기 |

- 틀 1개에서 한 번에 **2마리**가 구워집니다.
- 다 익은 뒤 **3초** 안에 꺼내지 않으면 탑니다.
- 반죽을 부을 때마다 재료비 **400원**이 보유금에서 빠집니다.

## 🙋 손님

```
[Q] 팥2 슈1      <- 자리 키와 주문 (팥 2마리, 슈크림 1마리)
   (^_^)
   /|\           진열대에 주문한 만큼 있을 때 Q를 누르면 판매!
   / \
[==========]     인내심 게이지: 초록 -> 노랑 -> 빨강
```

- 손님은 팥 · 슈크림을 합쳐 **1~3마리**를 무작위로 주문합니다.
- 판매 금액 = **1마리 가격 × 주문한 마리 수** (예: 1,000원에 팥2 + 슈1 → 3,000원)
- 판매 금액은 **바로 보유금**에 들어가서 그날 재료비로 쓸 수 있습니다.
- 인내심이 **60% 넘게** 남았을 때 주면 **단골 등록 + 팁 500원** (팁은 정산 때 지급)
- 인내심이 다 닳으면 화가 나서 돌아갑니다 (실수 +1).
- 표정이 `(^_^)` → `(-_-)` → `(>_<)` 로 바뀌고, 날이 갈수록 손님 성격이 급해집니다.

### 가격과 손님 수

비싸게 받으면 손님이 줄고, 싸게 받으면 많이 와도 남는 게 적습니다.

```
손님 등장 확률 (0.05초마다) = 1/50 × 날씨 배율 × (1000 / 가격)^1.6 × 1.25(간판이 있으면)
```

아침 준비 화면에 손님 예상(아주 많음 · 많음 · 보통 · 적음)이 표시됩니다.

## 📊 전광판 보는 법

```
일차별 매출 (단위: 천원)   누적 합계
+------+--+--+--+--+--+  +------+----+----+----+----+
| 일차 | 1| 2| 3| 4| 5|  | 가게 |매출|손님|실수|단골|
+------+--+--+--+--+--+  +------+----+----+----+----+
|라이벌|12|15|11|  |  |  |라이벌|  38|  19|   3|   2|
+------+--+--+--+--+--+  +------+----+----+----+----+
|  나  |14|13|16|  |  |  |  나  |  43|  21|   2|   5|
+------+--+--+--+--+--+  +------+----+----+----+----+
```

| 칸 | 의미 (원본) |
| --- | --- |
| 1~5 | 그날 매출, 천원 단위 반올림 (원본: 회별 점수) |
| 매출 | 총매출 (원본: R) |
| 손님 | 받은 손님 수 (원본: H) |
| 실수 | 탄 붕어빵 + 화나서 돌아간 손님 (원본: E) |
| 단골 | 빨리 받아서 팁을 준 손님 (원본: B) |

## 💾 세이브와 이어하기

- 하루 장사가 끝나고 **상점에서 "다음 날로"를 누르면 자동 저장**됩니다.
- 메뉴의 **"이어하기"** 로 다음 날부터 계속할 수 있습니다. 전광판 기록, 보유금, 산 물건, 난이도가 그대로 복원됩니다.
- 저장이 없으면 "이어하기"는 회색으로 표시되고 선택할 수 없습니다.
- 영업 도중이나 상점 안에서 끄면 그날은 저장되지 않습니다.
- 게임이 끝나거나 "게임 시작"으로 새 게임을 시작하면 저장 파일이 지워집니다.

## 🖥 다른 컴퓨터 호환을 위해 처리한 것

- **한글**: 소스가 UTF-8로 컴파일돼도 출력 직전에 CP949로 변환합니다.
- **키 입력**: 가상 키 → 입력 글자 → 한글 자모 → 스캔 코드 순서로 판단해서, 한/영 상태와 터미널 종류에 상관없이 인식합니다.
- **빠른 편집 모드 끄기**: 창을 클릭해도 게임이 멈추지 않습니다.
- **콘솔 창**: 콘솔이 없으면(디버그 실행 등) 새 콘솔 창을 직접 엽니다.
- **음악**: `winmm.dll`을 실행 중에 불러오므로 `-lwinmm` 링크 옵션이 필요 없습니다.
- **창 크기**: 창 크기를 바꾸면 화면을 가운데에 다시 그리고, 너무 작으면 안내합니다.
